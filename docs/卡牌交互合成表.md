# 🔄 StackFarming 卡牌交互合成表（109 卡）

> 单源交互表：覆盖原卡 + 扩展（★）。交互触发方式统一为：**【容】**=放入地形容器（占1格，按卡×容器交互逻辑运行）· **【叠】**=叠放自动触发 · **【劳】**=双手拖拽合成 · **【食】**=饲料卡喂养动物 · **【集】**=季节/自然采集。
> 容器语义：**每张地形卡是一个容器（占地 w×h 格）**，内容物放进容器按「卡型×容器型」交互；**内容物永不触发地形合成**（地形合成只在地形×地形本体叠放时发生）。详见 [[容器与种植规则]]。
> 编号沿用 [[卡牌数据总表]]（T1-T7 / F1-F3 / B1-B30 / TL1-TL11 / R1-R58）。

## 一、堆叠自动合成【叠】

> **容器语义**：地形合成只在地形卡×地形卡**本体叠放**时发生；容器内的内容物（作物/鱼/水/粪…）**永不触发**地形合成。
