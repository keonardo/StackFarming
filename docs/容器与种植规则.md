# 🌱 容器与种植规则（地形 = 容器）

> 状态：**设计稿（未实现）** | 更新：2026-09-01（细化：放置/取出、内容物互动、容量优先级）
> 核心概念：**每张地形卡是一个容器**，占地 w×h 格；放进容器的卡 = 内容物，按「卡型 × 容器型」的交互逻辑运行。内容物永不触发地形合成。
> 配套：[[基础玩法规则]]（网格/占地/合成/空位跳跃/双手劳作）、[[卡牌交互合成表]]

---

## 一、容器模型

```
地形卡 = 容器
├── 区域：w×h 格（网格占地，见基础玩法规则二）
├── 容量：= w×h（格数）
└── 内容物：放入的卡（生物/资源/工具），各占 1 格，在容器内铺开
```

- **内容物铺开而非叠栈**：卡放进化容器后，对齐到容器内的网格格点，视觉上分散在地形区域内（不是摞成一摞）
- 内容物之间、内容物与容器之间通过「卡×容器」规则交互（见三、四）

### 1.1 容量（格数）
| 容器（地形） | 尺寸 | 容量 |
|------|------|------|
| 池塘 | 2×2 | 4 格 |
| 大水塘 | 3×2 | 6 格 |
| 鱼塘 | 3×3 | 9 格 |
| 水田 | 2×2 | 4 格 |
| 塘基（旱地） | 2×3 | 6 格 |
| 深水鱼凼 | 2×2 | 4 格 |
| 山野林坡 | 3×3 | 9 格 |
| 厨灶/陶瓮/晒架 | 1×1 | 1 格 |

### 1.2 两类容量限制（详见五）
- **格容量** = w×h（静态内容物数量硬上限：作物/物质/设施）
- **类型上限** = 每类静态内容物的数量上限（如作物 ≤3），继承原「承载力」语义
- **动物不计入格容量**：动物是自由 Avatar（见六），只受「栖息类型上限」（如水域鸭 ≤2）约束，不占格子

## 二、放入 vs 合成（判定规则）

> 核心：**放进容器的内容物，永远不会让地形合成为其他地形。**

| 操作 | 判定 | 结果 |
|------|------|------|
| 拖卡到地形**范围内**（默认） | 容器有空格 且 该卡允许进入该容器 且 类型上限未满 | **放入容器** → 内容物 |
| 拖卡到地形**本体**上 | 该卡 × 该地形存在合成公式 | **触发合成**（地形合成只在此发生） |
| 拖卡到地形**本体**上 | 无合成公式 | 落入容器（等同放入） |
| 拖**地形卡**到另一地形卡本体 | 存在合成（池塘×池塘→大水塘） | 触发合成 |

### 2.1 关键约束
- **内容物不触发地形合成**：容器内已有的作物/鱼/水/粪……都不会让容器变成另一种地形
- 只有「地形卡叠地形卡本体」才发生地形合成；「鱼塘」不靠堆叠，而是**双手改造**「装≥2鱼的大水塘」（劳作配方）
- 同一格不能同时放两张内容物（格满即拒）

## 三、内容物交互逻辑（卡型 × 容器型）

每张内容物卡在容器中有自己的行为，按卡型分类：

> **工具卡例外**：工具（鱼竿/锄头/镰刀/石磨/织机/铁犁/猎弓等）**永不进容器**，保持自由卡身份。容器拒绝接收工具；工具以「双手劳作」拖到目标卡上使用（见 [[基础玩法规则]] 五）。设施类（厨灶/陶瓮/晒架）是独立容器，不受此限。

### 3.1 作物（生长）
| 内容物 | 可入容器 | 行为 |
|--------|---------|------|
| 菰米种 | 水田 | 湿润决定生长速度；成熟→菰米 |
| 菱角 | 池塘/大水塘 | 缓慢生长招虫；成熟→菱角(可再种) |
| 水稻 | 水田(润≥60) | 缺水掉血/更招虫；成熟→稻米×2+稻草 |
| 黄豆/桑树/梨树 | 塘基 | 旱作生长；周期产豆/叶/果 |
| 慈姑/荸荠/水芹 | 浅水/水田 | 水生蔬菜；成熟收果 |
| 芡实 | 深水荷花区 | 慢熟→芡实米(最高价) |
| 莼菜 | 水面 | 慢熟→莼菜 |
| 莲子→莲花 | 池塘 | 沉塘生长→莲藕/莲子 |

### 3.2 动物（自由 Avatar，不占格）

> **动物 ≠ 静态内容物**：动物是自由活物（Avatar），不受容器/网格限制，可自由移动。放入容器 = **指派栖息地**，不占格。详细见「六、动物 Avatar 双态系统」。

| 内容物 | 可栖息容器 | 行为 |
|--------|---------|------|
| 鸭子 | 池塘/大水塘/鱼塘 | Avatar 在栖息水域游动→回饱→产蛋/粪；吃虫；2鸭+蛋孵新鸭 |
| 鸡 | 塘基/旱地 | Avatar 啄食虫×1.5→产蛋；怕水 |
| 鹅 | 两栖容器 | 警戒防黄鼠狼 |
| 青蛙 | 水田 | 被动捕虫；旱季消失 |
| 泥鳅 | 水田底 | 松土→墒情衰减↓ |
| 黄鳝/螃蟹 | 深凼/水田 | 生长→鳝/大闸蟹 |
| 河蚌 | 水域底 | 净化+结珠（河蚌偏静态，可视为拟态 Avatar） |
| 鸬鹚 | 浅水/鱼塘 | 役用捕鱼×2 |
| 家犬 | 旱地/设施旁 | 巡逻防害 |

### 3.3 物质（效果，入容器即作用于整个容器）
| 内容物 | 可入容器 | 行为 |
|--------|---------|------|
| 水 | 水田/塘基 | 滋润/墒情↑，消耗 |
| 粪便 | 水田 | 生长 buff + 引虫 |
| 肥料 | 水田 | 生长×2.5 不引虫 |
| 稻草 | 水田/塘基 | 保墒 |
| 饲料(米糠/豆渣/浮萍/桑叶) | 含动物容器 | 喂养动物 |
| 塘泥 | 塘基/水田 | 肥力 |
| 蚕沙 | 鱼塘/水田 | 温和肥(不引虫) |
| 艾草 | 水田/塘基 | 防虫 buff |
| 水 | 污染水域 | 稀释污染 |

> **物质效果 = 容器级**：效果卡入容器后，其 buff/污染/湿润作用于**整个容器**，不是单格。效果持续到卡片 Duration 归零（或按配方消耗）。

### 3.4 净化植物（净化整个容器）
| 内容物 | 可入容器 | 行为 |
|--------|---------|------|
| 芦苇 | 浅水 | 吸污净化 + 蔓延 |
| 水葫芦 | 水域 | 极速吸污 + 失控蔓延 |
| 金鱼藻 | 鱼塘底 | 产氧稳净 |
| 河蚌 | 水域底 | 慢速底滤 |

### 3.5 设施（独立容器）
- 厨灶/陶瓮/晒架 = 1×1 独立容器，可放在空地或其他地形旁
- 设施可叠入内容物：厨灶装燃料+生食→熟食；陶瓮装食物→保鲜×3；晒架装鱼/肉/菱→干货

## 四、容器内内容物之间的交互（同容器生态）

> 判定域：**同一容器内**。交互分两类——**全局型**（对整个容器所有内容物生效）与**目标型**（对容器内特定目标卡生效，取最近格目标）。

### 4.1 全局型交互（容器级 buff / 环境效果）
| 效果来源 | 对容器内目标 | 效果 |
|---------|-------------|------|
| 泥鳅 | 整个容器 | 墒情衰减↓（松土） |
| 青蛙 | 容器内虫 | 被动捕虫（拦截悬浮虫，附身虫先卸除） |
| 金鱼藻/芦苇/水葫芦/河蚌 | 容器水质 | 污染↓ |
| 鹅 | 容器内的蛋/幼禽 | 黄鼠狼无法袭击（守点防御） |
| 家犬 | 容器内蛋/幼禽/设施 | 主动驱赶黄鼠狼（巡逻防御） |

### 4.2 目标型交互（捕食/增益/伤害，按最近格判定）
| 捕食者 | 猎物 | 判定 | 效果 |
|--------|------|------|------|
| 鸭子 | 虫（悬浮/附身） | 同容器内取最近虫 | 吃虫回饱（+40）；附身虫先从作物卸下再吃，虫消失 |
| 鸡 | 虫（悬浮/附身） | 同容器内取最近虫 | 吃虫效率 = 鸭×1.5 |
| 螃蟹 | 虫 / 弱苗 | 同容器内 | 吃虫（防虫）但也啄弱苗（双刃） |
| 黄鼠狼 | 蛋/禽 | 容器内（无鹅犬时） | 偷蛋/叼鸡 |
| 鸬鹚 | 鱼 | 容器内 | 役用捕鱼（×2 效率） |
| 河蚌 | 浮萍 | 同容器内 | 结珠加速 |

### 4.3 竞争与冲突
| 组合 | 冲突 | 结果 |
|------|------|------|
| 鸭 + 鸡 | 争虫 | 鸡优先抢虫（效率高），鸭可能断粮 |
| 蟹 + 作物苗 | 啄苗 | 弱苗健康↓；蟹太早放=苗灾 |
| 多种动物密度过高 | 占格 | 格容量/类型上限约束 |

### 4.4 繁殖/产蛋（容器内进行）
- 鸭子产蛋、鸡产蛋、水牛产奶 = 自身进度满 → 产物以**浮动卡**出现（见八）
- 鸭子孵化（2鸭+蛋）= 容器内条件满足 → 新鸭子直接 Avatar 出现（活物，不浮动）

## 五、容量与类型上限（优先级）

### 5.1 判定顺序（放入静态内容物时）
```
① 类型上限未满？ ──否──→ 拒绝放入（提示该类已满）
        │是
② 格容量未满（有空位）？ ──否──→ 拒绝放入（提示容器已满）
        │是
③ 放入，占最近空格
```

> **动物（Avatar）不占格**：动物「指派栖息地」只查「栖息类型上限」（水域鸭 ≤2 等），不查格容量。格容量只约束作物/物质/设施等静态内容物。

### 5.2 类型上限参考
| 容器 | 静态类型上限 | 栖息类型上限 |
|------|-------------|-------------|
| 池塘/大水塘/鱼塘 | 物质 ≤容量余量 | 鸭 ≤2 |
| 水田 | 作物 ≤3（与格容量 4 取小） | 蛙/泥鳅 ≤2 |
| 塘基 | 旱作 ≤2-3 | 鸡/犬 ≤2 |
| 深水鱼凼 | 物质 ≤容量余量 | 鳝/蟹 各 ≤2 |

### 5.3 规则要点
- **格容量是硬上限**：静态内容物总数 ≤ w×h（动物不计入）
- **类型上限是软上限**：在格容量内，每类再限数量
- **栖息类型上限**：动物数量上限，独立于格容量
- 提示区分「容器已满」「该类已满」「栖息已满」

## 六、内容物的放置与取出

### 6.1 放入定位
- 拖卡到容器范围 → 自动落到**最近的空格**（网格对齐）
- 手动微调：内容物可被拖动到容器内**其他空格**（换位置）
- 容器无空格 → 拒绝（见五判定）

### 6.2 取出
- **拖动内容物移出容器区域** = 取出（变回普通卡，恢复 1×1 自由放置）
- 取出的内容物保留其当前进度/健康/保鲜
- 取出后该格空出，可再放入其他内容物

### 6.3 容器间迁移
- 内容物从 A 容器直接拖到 B 容器 = 取出+放入（A 空格出，B 按放入判定）
- 迁移保留内容物状态

### 6.4 特殊：内容物拖动与「合成/劳作」的区分
| 玩家操作 | 结果 |
|---------|------|
| 内容物拖出容器边界 | 取出 |
| 内容物在容器内拖动 | 换格 |
| 内容物拖到另一张卡本体 | 触发该卡的合成/喂养（若存在） |
| 工具拖到容器内容物上 | 劳作/喂养（双手） |
| 工具拖到容器地形上 | **工具不进容器** → 以双手劳作拖到目标卡上使用（若该地形无对应配方则无效，工具保持自由卡） |

## 七、动物 Avatar 双态系统（Animal Duality）

> **核心：动物不是静态内容物，是「自由活物」。** 玩家不操作时，动物显示为 **Avatar**（小型角色精灵，自由移动，不受容器/网格限制）；玩家操作（拖拽/点击）时才短暂变回 **Card**（卡牌形态）。这一设计解除了「移动 AI × 容器」的矛盾，也让动物的「活着」有了视觉表现。

### 7.1 双态定义
| 状态 | 触发 | 视觉 | 行为 |
|------|------|------|------|
| **Avatar 态**（默认） | 玩家不操作动物 | 小型角色精灵（游水/啄食/爬行动画），头顶小血条/进度条 | 自由移动（移动 AI），不受容器/网格限制；主动觅食/产蛋/巡防 |
| **Card 态**（临时） | 玩家拖拽/点击动物 | 卡牌（完整面板 + 名称/双数值/进度条） | 可放入容器、喂食、买卖、叠放、合成 |

### 7.2 状态切换
```
玩家拖拽/点击动物 ──────────→ Card 态（抓在手上）
       ↑                            │
       └── 松开到目标/容器 ─────────┘
          ↓ 目标合适
     恢复 Avatar 态（在目标栖息地自由活动）
```

- **松开放到容器** → 指派栖息地 → 恢复 Avatar 在容器区域自由游动
- **松开放到空地/卡牌** → 按该处规则（合成/喂养/取出）执行 → 最终恢复 Avatar
- **拖出界面/丢弃** → 回到地图自由活动

### 7.3 Avatar 的移动规则
- **不受容器/网格限制**：Avatar 可游出栖息容器，到邻近水域/旱地觅食、追虫、巡防
- **有栖息偏好**：鸭偏好水域（离开过远会归巢），鸡偏好旱地，虫爬向作物
- **移动 AI 沿用既有**：鸭子（巡逻/追虫/归巢）、虫子（爬行/追作物）；边界由「容器覆盖格」改为「栖息偏好场」
- 跨容器猎食（如鸭吃邻塘虫）**允许**——Avatar 是活的，会主动过去

### 7.4 Avatar 与容器的关系
| 操作 | 结果 |
|------|------|
| 拖动物卡到容器 | **指派栖息地**（不占格，记录归属） |
| 动物 Avatar 主动离开容器 | 允许；仍归属原栖息地（可再回来） |
| 容器地形合成（池塘×2→大水塘） | 栖息动物 Avatars 自动迁移到新地形范围 |
| 动物死亡 | Avatar 消失 → 掉落死亡副产品（皮/毛/肉）为 Card |

### 7.5 产物落位
- 产蛋/产奶等产出 → 产物以**浮动卡**出现（见八）；孵蛋 → 新鸭子直接 Avatar
- 动物死亡 → 死亡副产品（皮/毛/肉）以浮动卡掉落
- 动物产出的资源卡不进入容器静态容量体系（独立浮动，玩家主动收）

### 7.6 虫（害兽）的附着机制

> **虫不是内容物，也不是自由 Avatar——是「附身病灶」。** 虫以悬浮态出现在容器上方，经随机次跳跃后，附身锁定到容器内的作物上。一作物最多叠一虫。

```
【刷新】虫刷出 → 悬浮于容器上方（待机，轻微弹跳）
   │
【跳跃】随机次跳跃（每次随机方向/距离，不掉格、不占容器格）
   │
【附身】跳入容器 → 叠加锁定到某株作物上（一作物最多叠 1 虫）
   │
【为害】附着期间持续啃食该作物（作物健康↓）
   │
【移除】被吃 / 被拖走 → 虫从作物上卸下，可作饲料/堆肥
```

- **刷新**：自然冒虫 / 惊蛰全田刷 → 均以悬浮态出现在对应容器上方
- **悬浮态不占格**：悬浮中的虫不占容器格容量、不参与地形判定；可被 Duck/Avatar 捕食
- **附身锁定**：跳入容器后锁定到一株作物上；该作物已叠 1 虫 → 虫另寻他株（或暂留悬浮）
- **附身影响**：附着作物持续掉健康；移除（吃/拖）后作物恢复
- **拖动**：悬浮虫 / 附身虫均可被拖起 → 变 Card 可喂鸭、堆肥、销毁
- **防虫时机双窗**：悬浮期（跳跃中）与附身期（锁定后）都可防——鸭/鸡/蛙拦截悬浮虫，附身后需先移除

## 八、产物浮动（Floating Yield）

> **核心：一切产物（除动物卡）都是浮动卡牌**——生成后以「浮动卡」状态飘在产出点附近，**在玩家操作前不落位**到网格或容器上。玩家不碰它，它就悬浮待取；玩家拿起，才进入正常卡牌/网格/容器体系。

### 8.1 适用范围
| 产物来源 | 产物形态 |
|---------|---------|
| 作物成熟（稻米/菱角/莲藕…） | **浮动卡牌** |
| 劳作合成（豆腐/咸鱼/米酒/丝绸…） | **浮动卡牌** |
| 堆叠合成（粽子/莲花…） | **浮动卡牌** |
| 物质效果（肥料/塘泥消耗后…） | **浮动卡牌** |
| 动物产蛋/产奶/粪 | **浮动卡牌** |
| 动物孵化/繁殖 | **新动物 = 直接 Avatar**（活物，不浮动） |

> **动物卡例外**：动物产出/孵化的是「新动物」，直接以 Avatar 态出现（活物在世界上），不做浮动卡牌。

### 8.2 浮动卡状态
- **位置**：生成在产出点附近（小偏移，视觉悬浮/轻微飘动动画）
- **不占格**：不吸附网格、不占用容器格位、不参与任何地形/容器交互判定
- **可被拖动**：玩家拿起 → 变成正常可拖卡牌 → 放下时按落点吸附网格/进容器/触发合成
- **保鲜照常**：Duration 倒计时照常走；过期消失（消失前闪烁警示）
- **可参与合成**：浮动卡可被直接拖到目标卡上触发合成/喂养/劳作

### 8.3 玩家操作前不落位
- 产物生成后**保持浮动**，除非：
  - 玩家拖动它（拿起 → 放下时落位）
  - 玩家用「收集卡」收拢（见 8.4，后续扩展）
- 系统**不自动**把产物塞进容器空位/网格——落位永远是玩家主动行为

### 8.4 收集卡（后续扩展，留接口）
- 计划：箩筐/篮子类卡牌，可收拢一片区域内的浮动卡 → 批量装入/搬运
- 当前不实现，仅保留「浮动卡可被批量收集」的语义空间

### 8.5 其他衔接
- **容器地形合成**（池塘×2→大水塘）→ **静态内容物全部跌落原地**（跌落 = 就地转为浮动卡），栖息动物 Avatars 迁移到新地形范围，新地形跳空位展开（见基础玩法规则四）
- **放养进容器** = 种植/养殖；**拖工具到目标卡** = 劳作（双手）；二者互不干扰
- 内容物随容器一起渲染（见九）

## 十、节气 × 容器（全局效果）

> **默认：节气效果为全局**，一次性作用于**所有容器**，不做容器级差异化。单个容器的免疫/特例单独标注。

### 10.1 全局节气效果
| 节气 | 作用 | 容器表现 |
|------|------|---------|
| 惊蛰 | 全田刷虫 | 所有容器上方出现悬浮虫 → 跳跃附身作物 |
| 芒种 | 露天滋润骤降 | 所有水域容器滋润同时下降（全局，非逐容器） |
| 霜降 | 杀虫/生长减半 | 所有容器内的虫清除；作物生长全局减速 |

- 触发方式：节气切换时 SolarTermEngine 广播一次全局效果 → 各容器统一响应
- 无需逐容器查询/判断，简化为一次全图应用

### 10.2 容器级例外（单独标注）
| 容器 | 例外 |
|------|------|
| **深水鱼凼** | 芒种滋润骤降**免疫**（深凼保温，全局效果对凼置空） |
| 山野林坡 | 芒种反而雨丰（采集刷新↑，与全局旱相反） |

> 设计取舍：全局效果 = 实现简单、节奏统一；容器例外 = 数量极少、语义清晰（深凼/林坡），不破坏「节气全局」的默认假设。
