> 状态：**设计稿（未实现）** | 日期：2026-08-29
> 本规则覆盖 **所有卡牌**（原 22 + 扩展 87），是卡牌放置/合成/劳作的基础层。
> 配套：[[卡牌数据总表]]、[[卡牌交互合成表]]

## 一、网格系统（Grid）

### 1.1 基础网格
- 全场景统一网格，**格距 = 卡牌基础尺寸（宽 80px × 高 100px）**，矩形网格（与卡牌面板一致）
- 所有卡牌在**放置落定**时自动吸附到最近格点：`global_position → round(pos / cell_size) × cell_size`
- 网格只约束「落定位置」，拖动过程仍自由跟手；松开时才吸附

### 1.2 卡牌占格
| 卡类 | 占格 |
|------|------|
| 地形卡 | **W×H 多格**（见二） |
| 设施卡（厨灶/陶瓮/晒架） | 1×1 |
| 生物 / 资源 / 工具卡 | 1×1（叠在栈上，不额外占地面格） |

### 1.3 判定
- 网格中心点 = 卡牌锚点；地形展开后其覆盖格 = 地形区域
- 拖放落定时，以「卡牌锚点 + 目标卡碰撞」判定落到哪块地形上（用于叠加/种植）

## 二、地形卡尺寸与展开（Terrain Size）

### 2.1 尺寸属性
- 每张地形卡新增属性 **size (w×h)**，单位 = 格数
- 放置到网格后，**自动向右下展开**成一片地形图案（覆盖 w×h 格）

### 2.2 地形尺寸表

| 地形 | 尺寸 | 说明 |
|------|------|------|
| T1 池塘 | **2×2** | 基础水域 |
| T2 大水塘 | **3×2** | 池塘×2 合成 |
| T3 鱼塘 | **3×3** | 双手改造「装≥2鱼的大水塘」 |
| T4 水田 | **2×2** | 农田 |
| T5 塘基（旱地） | **2×3** | 锄头+池塘 |
| T6 深水鱼凼 | **2×2** | 铁犁+鱼塘 |
| T7 山野林坡 | **3×3** | 自然/购 |
| F1 厨灶 / F2 陶瓮 / F3 晒架 | **1×1** | 设施 |

### 2.3 地形互斥
- 一张地形卡覆盖的 w×h 格内，**不能再放置任何其他地形卡**
- 重叠放置：拖放落点被已有地形区域覆盖 → 拒绝落定（除非是叠放在该地形**本体**上做合成）
- 地形卡之间至少相距 1 格（视觉上允许贴边，占地不重叠）

## 三、合成触发规则（叠加 ≠ 范围）

> 核心：**地形卡的合成只能靠「叠放在本体上」触发，不能靠「落在其地形范围内」触发。**

### 3.1 合成判定
- 地形卡要合成：把原料卡**拖到地形卡本体上**（形成栈/吸附），才检测该地形卡的合成公式
- 原料卡只是**落在地形范围内**（不在本体栈上）→ **不触发**与地形卡的任何合成公式
  - 例：鱼落在池塘范围内但没叠上池塘本体 → 不触发「鱼+池塘」相关判断（若有）
- 生物/资源/工具卡**允许落在地形范围内**（占地作为场景物），但合成与否只看「是否叠上本体栈」

### 3.2 合成类型不变
- 堆叠合成【叠】：拖到地形本体上自动触发（原规则保留）
- 劳作合成【劳】：拖工具到目标卡上触发（= 玩家的双手，见五）
- 放养【养】：生物/作物拖到地形范围内/本体上放置（受地形尺寸与承载力约束）
- 喂养【食】：饲料拖到动物本体上

### 3.3 种植与合成分离（种植可在地形范围内，合成只在本体上）
- **种植【养】✅ 允许**：生物/作物卡可以放置在地形**范围内**生长（如池塘里种菱角/莲花、水田种稻），不受「只认本体」限制
- **合成【叠】❌ 只认本体**：能触发地形卡合成公式的，只有叠放在地形**本体**上的卡
  - 例：把菱角落在池塘范围内 → 是种植，正常生长
  - 例：把鱼落在池塘范围但不叠本体 → 不触发鱼+池塘相关合成（若有）
- 详细种植规则（承载力/覆盖格数/生长判定）**另行设计，本稿不展开**

### 3.4 网格对合成的影响
- 网格吸附仅影响**放置位置**，不影响栈关系（栈关系 = 谁叠在谁上）
- 地形本体上可叠的卡数仍受地形**承载力**限制（与尺寸解耦）

## 四、新合成地形的空位跳跃（Auto-Dock）

- 新合成出的地形卡（如 池塘+池塘→大水塘）**不留在原地**，而是**自动搜索最近可容纳区域**（满足自身 w×h 且不与其他地形重叠），跳跃展开
- 搜索优先级：
  1. **优先复用**：原地形消失释放出的空格（原地/紧邻位置）
  2. 次选：原地向右下螺旋扩展的最近空区
- 若无可用空位 → 落回原地（暂时重叠，需玩家手动腾位）
- 目的：避免「合成新地形把旧地形顶出 / 叠叠乐」的混乱，保持地形互斥干净

## 五、劳作 = 玩家的双手（Labor = Player's Hands）

> **劳作不是卡、不是站、不可购买**。它就是玩家拖拽卡牌合成这一动作本身——你在游戏里没有「工作台」实体，你的手就是劳作工具。

### 5.1 核心机制
- 所有合成（堆叠合成 + 劳作配方）都是**玩家手动把卡拖到目标卡上**触发的动作
- 不需要任何「劳作台/工作台」卡或 UI 区
- 拖拽完成的一刻 = 劳作发生；进度条直接显示在目标卡上

### 5.2 劳作流程（纯拖拽）
1. 玩家拿起工具卡，拖到目标卡上
2. 若构成配方 → 开始合成（进度条浮在目标卡上方，时长 = 基础时长 ÷ 效率）
3. 进度满 → 产物卡出现，工具 -1 耐久
4. 产物落到旁边/叠到目标上，完成

### 5.3 与现有 UI 的关系
- 移除常驻 UI 劳作区、移除「劳作台」概念、移除劳作站场景
- 合成的唯一入口 = 玩家的拖拽动作
- 长工等自动劳作已移除，无任何「自动劳作」实体

## 六、对现有系统的连锁影响

| 系统 | 影响 |
|------|------|
| **拖动吸附** | BaseCard 落定时按网格取整 |
| **地形注册** | IrrigationManager 记录地形覆盖格集合（用于互斥/寻址/邻接） |
| **水系邻接** | 邻接判定改为「覆盖格相邻」而非圆心距离（更精确） |
| **物质漂移** | 下游判定改为「覆盖格相邻/相接」 |
| **移动 AI** | 动物为 Avatar 双态：玩家不操作时自由移动（不受容器/网格限制），移动 AI 沿用现有巡逻/追虫/归巢；栖息偏好取代固定边界 |
| **集市/购买** | 设施落地同样走网格 |
| **新卡尺寸** | 扩展设计中的新增地形需补 size 字段 |
