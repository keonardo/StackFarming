## 一、扩展思路

两个环，通过物质载体咬合成一个自循环：

```
【水系环】池塘/大水塘/鱼塘/水田 —— 鸭/鱼/蟹/莲/菱
                                   ↕  塘泥、蚕沙、豆渣
【旱地环】塘基 —— 桑树/黄豆/艾草 （新增地貌）
```

```
种植/养殖收获 ──→ 副产品 ──加工/酿造/腌制──→ 高价品
      │                │                        │
      └── 汇回生态（叶喂鸭 / 渣回田 / 塘泥肥基）──┘
```

每批新卡必须满足：**至少与 2 张现有关卡发生合成**，杜绝孤立卡。

**水八仙宴席（收集奖励）**
- 集齐 8 种水八仙果实 → 集市解锁「宴席」：一次收购全部 8 种 → 高价回报（≈单卖总额 ×1.6）+ 声望/节庆奖励

**涌现点**：种什么吃什么是日常，但「水八仙」把 8 种水生作物串成隐藏成就——玩家为了集齐会主动尝试「没种过的水生作物」，收获前的空白生态让每种作物都有被种的机会。

**关键机制**
- **蛋锁定**：鸡蛋/鸭蛋在「无鹅守护」的农场 = 黄鼠狼的诱饵。玩家要么圈鹅防，要么把蛋集中放到有鹅的存蛋点。
- **鹅是防御塔**：警戒半径内的黄鼠狼持续被吓 → 游走不袭击 → 玩家用「一鹅守三仓」布点。
- **黄鼠狼皮**(R41)：击退黄鼠狼掉落 → 集市高价 / 可作高级「毛笔/裘」材料（二期）。

**涌现点**
1. **鸡鸭二选一**：鸡吃虫更狠→鸭子断粮；但鸭能避芒种水灾、鸭蛋走孵化链。混养强度换你的心思。
2. **青蛙 = 托管生态**：种好蛙就不操心虫，但蛙怕旱——「防虫自主权」随气候波动。
3. **黄鼠狼 = 风险放大器**：前提是「养禽越多越招」——玩家要决定**蛋是财富还是饵**。

| 水牛 + 稻草/米糠/浮萍/桑叶 | 牛健康↑ + 役用进度↑ | 饲料转化 |
| 水牛 + 水/稻田/池塘 | 泡水（健康稳） | 水牛犁田意象 |

| 水牛(死亡) | 水牛皮×1 | 重役代价 |

**涌现点**
1. **饲料有了大消费者**：稻草/米糠/浮萍/桑叶此前是「卖几个钱」的边角料，水牛让「攒饲料=蓄能」。
2. **杠杆 choice**：牛×2 跟石磨叠加怎么算？留白给玩家试（相乘 or 累加是平衡题）——投入产出从「慢快」变「算账」。
3. **重役风险**：牛死皮贵，但役用太猛牛会真死——现代化潜台词，古代版「压榨 vs 善待」。

### M. 动物体系总纲（统一机制框架）

> 设计核心：所有动物（已有鸭/虫 + 新增鸡/蛙/鹅/黄鼠狼/水牛）共用一套代码路径——生命周期/投喂/副产/死亡 **由配置表驱动**，不每种单独写逻辑。保证「极简双数值」原则贯穿。

#### M1. 三态生命周期（全部动物通用）

```
【幼体】集市购/亲代繁殖 ──成长进度B满──→ 【成年】──副产进度B满──→ 【生产】
  低健康、吃得多、无副产    可繁殖+开始生产循环        产蛋/奶/绒/皮 → 重置

【成年】健康归零（饿/旱/疫）→ 【死亡】→ 皮/毛/肉副产品
```

- **幼体 = 低阶生物卡**（雏鸡/雏鹅/牛犊/蝌蚪）：能跑能死，只是不生产——「养大成兽」是真实责任，不是买蛋即产
- 副产品全程挂在「死亡」与「生产」两条出口，不额外加属性

#### M2. 四维属性（每只动物填同一张表）

| 维度 | 含义 | 体例 |
|------|------|------|
| **栖息地** | 水 / 旱 / 两栖 | 决定移动域与灾感（水灾/旱灾） |
| **食物** | 吃虫 / 吃饲料卡 / 被动挂机 | 决定饲料链归属 |
| **生产间隔** | 副产周期（B 值） | 决定收益节奏 |
| **死亡副产品** | 皮/毛/肉 | 决定「杀 vs 留」决策 |

#### M3. 统一玩家语言

- **投喂**：拖饲料卡叠动物 = 回健康 + 副产进度↑（对全部动物通用）
- **收产**：生产进度满 → 自动落副产（沿用鸭子产蛋逻辑）
- **移动**：食虫类成年走移动 AI；役畜/家禽可控拖拽
- **偏好饲料机制**：任何饲料卡能喂任何杂食动物，但**偏好者回健康 +50%** → 「谁最爱吃什么」是玩家隐性知识，喂对高回报

#### M5. 两个体系级机制

1. **饲料链通用**：任何饲料卡都能投喂任意杂食动物，偏好者 +50% 回血 → 玩家记住「谁最爱吃什么」是隐性知识，喂对高回报
2. **害兽响应曲线**：家禽密度（鸡鸭鹅总数）↑ → 黄鼠狼刷出概率↑；鹅数量↑ → 黄鼠狼被压制 → **养禽即布防**

**落地收益**：7 种动物共用一套生命周期/投喂/副产/死亡代码，配置表驱动新增动物只需加一行，不新增系统。

2. **野味 vs 种植**：野生产量不可控但**免费**，养殖可控但要投入——高玩会「野生打底、养殖精进」双轨运营。
3. **山菌赌博**：未认领的山菌有 10% 毒菌概率（鉴别需耐心/经验）——「捡了可能白捡、可能中毒」。

**关键机制**
- **鸬鹚 = 水上役畜**：和水牛对称的「役用×2」，但管的是鱼塘；喂鱼成本 vs 渔获翻倍的账，和水牛的饲料账一模一样 → 两套役用系统共用一套「喂料→效率」逻辑（进 M 纲）
- **狩猎随缘**：野禽警觉高——直接扑会惊跑，需猎弓慢速接近；低效但免费 → 「守株待兔」的野趣
- **鸬鹚 vs 渔网**：渔网×4一次性、鸬鹚×2持续——「买断工具」vs「养只牲口」的经营差异

**涌现点**
1. **役用双生**：水牛陆×2 + 鸬鹚水×2，「养牲口换效率」成为与「买工具换效率」并行的第二条升级线。
2. **狩猎经济**：山雉/野兔免费刷新，但猎到手要运气和时间 → 「满载而归 vs 空手下山」的情绪曲线。

### T. 护院家犬（犬 — 巡防与看护）

> 设计核心：鹅是「守点防御」（警戒圈内抗黄鼠狼），犬是「巡逻防御」——主动把靠近的害兽赶得更远，且能保护蛋/幼禽。「守点 + 巡线」两道防线齐活。

| # | 名称 | 类型 | 健康 | 进度 | 来源 | 交互逻辑 |
|---|------|------|------|------|------|----------|
| B29 | **家犬** | 生物 | 100 | 0(忠诚) | 集市购幼犬 | **巡逻防害**：游走警戒圈；靠近黄鼠狼即驱赶（比鹅更主动）；护蛋/护幼禽；可拴守设施（守陶瓮/厨灶防偷）；忠诚度随投喂↑ |

**关键机制**
- **守 + 巡 双防线**：鹅（定点范围内害兽无法袭击）⊕ 犬（巡逻主动驱赶）→ 玩家布局「鹅守囤蛋点、犬巡鸭场」的防御阵列
- **活动忠诚**：投喂=忠诚度↑→巡逻半径↑。饿犬会旷职 → 「喂不饱的守夜人」

**涌现点**
1. **家犬 = 农庄的"人"味**：它不吃生产函数，却让「菜园/囤储」有了被守护的故事感。
2. **多害兽应对**：黄鼠狼怕犬怕鹅，但若玩家不养任何防害单位 → 家禽密度高原地招狼 → 养禽必配防 = 隐形义务。

### U. 水底经济（河蚌 + 珍珠 — 静谧的隐藏财富）

> 设计核心：水面、水中、水下——水底是最没被利用的层。河蚌是「静资产」：养在水底慢慢结珠，期间靠滤食净化水质（= 第四档生物净化）；珍珠是山野药材之外第二条「高价值通货」。

| R | 名称 | 类型 | Intensity | Duration | 来源 | 用途 |

**关键机制**
- **净化第四档**：金鱼藻（稳）/芦苇（可控蔓延）/水葫芦（极速失控）之后，河蚌是「不知不觉的慢速底滤」——与金鱼藻可叠加，污染重的水底放一堆蚌
- **浮萍联动**：浮萍覆盖水面 → 河蚌结珠加速（浮萍供食）→ 养浮萍不再只是「鸭饲料",也是「珍珠的隐形助力」
- **养珠周期**：结珠进度极慢 → 「三年不开张、开张吃三年」的耐心投资回报

**涌现点**
1. **水底景观**：河蚌养在哪 → 珍珠留在「你看不见的水下」——存钱存进池塘里。
2. **净化 + 蓄财**：蚌既治污又攒珠 → 高污染鱼塘的「哀房变身金库」，把负面状态翻成正面资产。

## 六、涌现设计意图

1. **桑基闭环自转（合肥）**：塘泥→塘基→桑叶→蚕沙→鱼→塘泥，水系+旱地两环由三种物质载体咬合，无需集市即可自转生产。
2. **塘基 = 空间权衡**：开一块塘基要牺牲一个池塘 → 水源 vs 旱作的持久取舍，每局不同。
3. **惊蛰布防**：艾草让「被动挨打」变成「有准备的攻防」——节气从单向威胁变成双向时钟。
4. **粽子 = 应急粮**：旱涝双危机都有储备对策（稻草保墒 / 咸鱼/粽子长保鲜）。
5. **豆渣/蚕沙 = 不引虫的净肥**：补上「施肥 vs 引虫」的设计矛盾（粪便引虫，净肥不引）。
6. **咸鱼跨旱期保险 / 米酒外卖 / 莲花慢沉淀资产**：同前稿。
7. **品种渐变 = 农耕文明升级**：菰米(野生)零维护低产 → 水稻(栽培)高产但「招虫更多+缺水掉血+占田更久」，玩家升级时要把灌溉/防虫/轮作整套工具链一并配套，呈现「技术换更高产出、也换更重责任」。
8. **驯化本身就是条长线**：集市买稻种是一次性捷径，续种靠每次收获留种（一代才积一仓）——古典养成的仪式感；后续甚至可反哺「水稻种+塘基」育出直连旱地的水路两栖種子变种（留白）。
