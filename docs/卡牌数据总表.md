# 🃏 StackFarming 卡牌数值总表（原卡 + 扩展整合版）

> 核心规则：每张卡牌的动态属性不超过 2 种（ValueA + ValueB）。
>
> 设计哲学：先有产出 → 才有扩展 → 形成闭环。
>
> 本表为**单源总表**：整合原有 22 卡 + 扩展 87 卡。扩展卡标注 ★，其设计依据/A-U 节涌现分析见 [[卡牌扩展设计_副产品加工系]]。
> 卡池合计：**109 张**（地貌 6+设施3 / 生物 30 / 工具 11 / 资源 58）。

---

## 一、卡牌类别体系

| 类别 | ValueA | ValueB | 说明 |
|------|--------|--------|------|
| **地貌 (Terrain)** | 承载力 | 环境值 | 承载生物、影响生长/繁殖速度 |
| **设施 (Facility)** | 容量 | 保鲜/功能 | 加工业：熟食、仓储、干制 |
| **生物 (Creature)** | 健康 / 耐久 | 进度值 | 生长、产卵、被虫啃 |
| **工具 (Tool)** | 耐久 | 效率 | 放入劳作区反复产出 |
| **资源 (Res)** | 强度/含量 | 存续时间 | 食物、原料、水 |
