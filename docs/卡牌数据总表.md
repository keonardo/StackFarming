# 🃏 StackFarming 卡牌数值总表

> 核心规则：每张卡牌的动态属性不超过 2 种（ValueA + ValueB）。
>
> 设计哲学：先有产出 → 才有扩展 → 形成闭环。

---

## 一、卡牌类别体系

| 类别 | ValueA | ValueB | 说明 |
|------|--------|--------|------|
| **生物 (Creature)** | 饥饿值 / 耐久 | 进度值 | 生长、产卵、被虫啃 |
| **资源 (Res)** | 强度/含量 | 存续时间 | 食物、原料、水 |
| **地貌 (Terrain)** | 承载力 | 环境值 | 承载生物、影响生长/繁殖速度 |
| **工具 (Tool)** | 耐久 | 效率 | 放入劳作区反复产出 |

## 八、开局卡牌与进度节奏

### 初始

| 卡牌 | 数量 | 用途 |
|------|------|------|
| 池塘 | 1 | 放鸭子 / 钓鱼 / 产水 / 种菱角 |
| 鱼竿 | 1 | 劳作：鱼竿+池塘=鱼 |
| 鸭子 | 2 | 放池塘产蛋；饿死有鸭毛；2只+蛋孵新鸭 |

### 第二阶段

```
卖鱼/蛋/毛 → 攒 8 块 → 买锄头
锄头+大水塘 → 水田 + 概率(菰米种/菱角/更多池塘)
菰米种→水田    菱角→池塘
	 ↓               ↓
  生长冒虫         生长冒虫
	 ↓               ↓
  收菰米          收菱角(可种回)

攒够 12 块 → 买引水车 → 放在水田上 → 自动从周围池塘吸水灌溉
→ 不用手动产水拖水 → 菰米生长全程高速 → 彻底解放双手
```

### 第三阶段：扩张

```
池塘×2 → 大水塘（承载力6，可养2只鸭）
2鸭 + 蛋 on 大水塘 → 孵化 → 新鸭子 → 鸭群翻倍 → 更多蛋/钱
```

### 第四阶段：自动化

```
大水塘 + 鱼×2 → 鱼塘（自动产鱼，不用鱼竿）
鱼塘养2鸭 + 自动产鱼 → 双线收入（鱼+蛋）
```

> 例：余额 80💰 → 先扣 20 免征额 → (80-20)×30% = 18💰 税

### 声望机制

|------|------|

| 声望不降 | 花钱不影响声望 |

  3. 菰米 → 吃掉

## 十、生物移动系统 (Movement AI)

### 行为状态机

```
鸭子：
  空闲(Idle)──巡逻徘徊──→ 检测范围内有虫？──→ 追击(Chase)──加速追虫──→ 接触→吃掉→回Idle
  追击(Chase)──虫消失/离远──→ 回Idle
  离开水域时──→ 自动向最近水域靠拢（找到后恢复Idle）

虫子：
  空闲(Idle)──巡逻徘徊──→ 检测范围内有作物？──→ 追击(Chase)──加速爬向作物──→ 接触→附着攻击
  追击(Chase)──作物死亡/离开──→ 回Idle
```

### 移动边界规则

| 条件 | 鸭子 | 虫子 |
|------|------|------|
| **有地貌时** | 约束在地貌周围 ±120px（水域内徘徊） | 约束在地貌周围 ±80px（不离地块太远） |
| **无地貌时** | 自由移动（但饥饿中会主动找水域） | 自由移动 |

### 检测与速度

| 参数 | 鸭子 | 虫子 | 说明 |
|------|------|------|------|
| 检测范围 | 150px | 80px | 发现目标的视野半径 |
| 空闲速度 | 30 px/s | 15 px/s | 巡逻徘徊时 |
| 追击速度 | 120 px/s | 60 px/s | 发现目标后加速 |
| 转向间隔 | 2~4s 随机 | 1.5~3s 随机 | 空闲态随机换方向 |
| 归巢权重 | 离水域 >200px 时主动返回 | — | 鸭子专属 |

### 空闲漫步方式（巡逻型）

| 生物 | 巡逻模式 |

| **鸭子** | 在地貌范围内左右摆荡：沿水平轴 ±随机偏移，偶尔短距冲刺，模拟水面觅食 |
| **虫子** | 在地貌范围内慢速蠕行：随机小步移动 + 偶尔停顿，模拟爬行 |
